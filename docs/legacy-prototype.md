# Legacy prototype

Before the trunk replacement, `main` held an earlier sample-data prototype for Manhattan CB3 with these screens: Home, Tickets (List, Kanban and Roadmap views), Calendar, Templates, Outreach (editable social post previews), Forum (board-to-board), and Dashboard. It had no persistence.

It is not part of V1 or V2. Outreach, Templates and the Dashboard map onto V3 asset generation and data aggregation (see section 2 of `refactor-spec.md`).

The code is still reachable as the parent of the trunk commit (old `main` tip `ba965c5`, 2026-10-27). The old `staging`, `ideal-state` and `bcb9` branches also still exist on the remote.
